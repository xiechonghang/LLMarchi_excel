审核时建议逐项记录

  1. 层级与数量：2+1+20+20=43 层、4 组是否与模型 config 一致；MTP 层 78 是否明确不在主干。
  2. 主链与分支：是否单向、无向上回流；残差/分支是否向下游汇合；是否有一眼看不明白的长线。
  3. 维度与命名：箭头是否标形状且用全称（batch_size/seqlen/kv_sequence_length/q_lora_rank…）；Linear 是否保留实例名（q_a_proj 等）。
  4. 缓存与状态：主 KV、压缩 KV、indexer 缓存是否前态→计算→后态；有没有把历史长度和本次长度混用。
  5. Attention / Indexer：Q 低秩、共享 KV、csa/hca 压缩与 top-k 选择是否可读；raw 与 normalized 的差异是否看得出来。
  6. FFN / MoE / mHC：MoE 路由是否标为未知、专家模板是否只展开一份；mHC 4 流是否读得懂。
  7. 来源：节点卡片里的源码文件/行号是否能对上 hflib/transformers@536ecc0。
  8. Excel：公式是否可编辑、未知输入是否不按 0 计、层组小计与整网串行汇总是否合理。
  9. 整体：哪几张图需要重排/合并/拆分；哪些文字需要改写；哪些信息希望默认展开。
