# DeepSeek 结构阅读正式集成规格

日期：2026-11-01（Asia/Shanghai）。范围：DeepSeek-V4-Flash-0731。状态：规格已形成；完整交付入口验收边界已获用户确认；尚未拆票、派发或实施。本规格不构成 T14 验收。

发布入口：[GitHub Spec #16](https://github.com/xiechonghang/LLMarchi_excel/issues/16)，标签 `ready-for-agent`。此标签表示规格可用于后续拆票，不代表已向dsh派发。

## Problem Statement

使用者希望从模型整网进入 Decoder，再读清 Attention、mHC、MoE 的算子与张量数据流。已有产品同时呈现旧结构图和 Archify 图、多个具体数值场景及大量辅助内容，模块抽象和算子展开混杂。部分图的文字、来源、残差依赖、连线标签和画布边界不完整；只修示例图的方式使同类错误反复出现。

第八版讨论草稿已获得展示方向认可，但它是独立原型，含手工组织的图和 reader 样式副本；尚未接入正式构建，也未完成实际浏览器目检。需要把认可的阅读方式接入已有确定性结构管线，并对最终全部图及离线页面验证。

## Solution

从现有 DeepSeek 构建入口生成一套离线、以 Archify 为唯一绘图方式的四层阅读产物。页面只提供 Prefill 与 Decode，图中始终传递符号形状。使用者可从整网进入 Decoder、模块关系与内部通路；简单端点在整网层就能查看算子细节。参数靠近对应图，来源与完整数据流按需联查。

以已认可的第八版为展示基准，按源码纠正或补齐原型中的抽象与覆盖不足。保留原有 Excel、历史候选和证据，不将原型直接替代正式结构事实。先完成 DeepSeek，由用户 review 后再另行决定其他模型推广。

## User Stories

1. 作为模型结构阅读者，我希望只选择 Prefill/Decode，以便不被额外场景干扰。
2. 作为阅读者，我希望 seqlen、kvcachelen、batch_size 沿全图保留为符号，以便理解结构而非单个示例。
3. 作为阅读者，我希望区分逻辑历史和物理保留缓存，以便正确理解窗口与压缩。
4. 作为阅读者，我希望只看到 Archify 图，以便不重复阅读两套图。
5. 作为阅读者，我希望整网对应 ForCausalLM，以便识别 Embedding、Decoder 循环、输出端。
6. 作为阅读者，我希望 Decoder 按真实层序循环而不全部铺开，以便同时看清重复与差异。
7. 作为阅读者，我希望在第一层查看 Embedding 的实际操作，以便跟踪输入轴变化。
8. 作为阅读者，我希望在第一层展开 HyperHead、Norm、lm_head 的算子，以便不把复合模块误认成一个算子。
9. 作为阅读者，我希望模块图和算子图明确区分，以便知道哪些内容仍未展开。
10. 作为阅读者，我希望所有“未展开”模块有实际展开入口，以便继续下钻。
11. 作为阅读者，我希望单个 Decoder 展示两段 mHC、Norm、Attention、MoE 与残差，以便读清完整层行为。
12. 作为阅读者，我希望看到 collapsed 送入 Attention/FFN 以及其输出参与后续合并，以便读清 mHC 的使用上下文。
13. 作为阅读者，我希望 Q/KV 在 Attention 总览中保持关联，以便理解它们如何汇入注意力核心。
14. 作为阅读者，我希望每个多输入箭头有来源、张量名及符号形状，以便不靠猜测识别输入。
15. 作为阅读者，我希望分别进入 Q、KV、O 通路，以便识别具名 Linear、Norm、布局与旋转操作。
16. 作为阅读者，我希望分别查看 SWA/CSA/HCA 的缓存路径，以便不把不同层型当成同一计算。
17. 作为阅读者，我希望 CSA 压缩、HCA 压缩和 Lightning Indexer 有真实细节，以便识别压缩条目、重叠状态及可见性。
18. 作为阅读者，我希望 MoE 关系层只显示路由、被选专家和共享专家，以便不被专家内部算子淹没。
19. 作为阅读者，我希望分别查看 Hash/TopK 选专家和计权差异，以便不混淆查表与 TopK。
20. 作为阅读者，我希望在下一层查看激活专家及共享专家的计算，以便理解输入规模与输出合并。
21. 作为阅读者，我希望图前提供精简参数，详情保留权重与源码，以便在必要信息和可追溯性之间切换。
22. 作为阅读者，我希望文字完整、标注贴近对应线、整图不被裁切，以便直接读懂图而非依赖工具提示补全。
23. 作为阅读者，我希望离线页面切换、返回、滚动、缩放和单独打开都可用，以便持续阅读复杂模型。
24. 作为使用者，我希望旧 Excel 与历史产物保留，以便新图不会改变既有性能表和验收证据。
25. 作为评审者，我希望同类缺陷在全图库中检查，以便每次反馈形成整体改进。
26. 作为评审者，我希望交付明确区分草稿认可、自动检查和人工目检，以便准确判断是否可以验收。

## Implementation Decisions

### 复用、扩展与新增

- **直接复用**：静态源码/config 核验、整网及真实层组结构、具名算子/张量引用、DeepSeek 语义 bundle、已存在的保守化简规则、Archify 工具发现与生成封装、候选来源清单、原子产物交付及 Excel 导出。复用以核对适用性为前提，不能因已有测试通过认定显示满足新要求。
- **扩展**：正式分层阅读页面、DeepSeek 图请求与语义投影、参数全称映射、布局与画布计算、来源/关系联查以及交付身份记录。新增端点、通路和节点变化进入同一事实与图生成管线。
- **新增行为**：四层章节导航、仅两阶段的符号阅读视图、整网层简单端点的算子展开、MoE 关系/专家分层入口、全部图的显示覆盖清单与最终浏览器验收证据。可沿既有模块扩展；不要求复制一套构建器或引入新框架。
- 草稿只提供经认可的设计决策与反例；不将其手写节点、图数、坐标、标题或 HTML 字节作为正式构建的真值。

### 阅读与符号契约

- 四层分别是：整网；一个 Decoder；mHC/Attention/MoE 模块关系；内部算子/通路。真实层型选择可作为这些层级的上下文，不额外制造一整套重复浏览层。
- 整网以 DeepseekV4ForCausalLM 为入口，含 Embedding、多流扩展、Decoder 循环、HyperHead、最终 Norm、输出位置选择和 lm_head。循环次数来自 config；当前配置43层，不能硬编码成所有配置的事实。同组模板不表示共享参数。
- Embedding 展示查表/Gather 与多流扩展的轴变化。输出端展开 HyperHead 的展平/精度转换、归一化、具名投影、门控、乘法及归约，再到 Norm、位置选择和 lm_head；logits_to_keep 决定输出位置长度，不强制跟随 Decode 变成1。
- 模块级复合节点必须明确未展开并提供入口；算子级保持具名语义粒度，Linear 同时显示实际实例名。Norm/RoPE 不机械拆尽全部微操作；图中保留 View/Transpose/Split 的形状与轴语义，不宣称必定为独立设备任务。
- Prefill 使用空历史约束 kvcachelen=0；Decode 保留 kvcachelen 与 seqlen。图内不代入示例 seqlen=8，也不强制 Decode 的 seqlen=1。固定轴1、真实层数等结构常量可说明来源。
- 全称参数和可追溯的派生表达式用于所有主图、标签、卡片及就近参数表。不得为显示方便虚构 config 字段。既有数值场景如为 Excel/其他工具所需，可以保留在内部与历史产物中，不继续出现在本轮阅读 UI。
- 第三层的 Attention 保留 Q/KV 关联的同图总览，分别表明输入 hidden_states、Q、可读 KV、mask 与辅助输入的真实身份。修标注不得将总览拆成互不关联的分图。第四层分别展示 Q、KV、O、三类缓存与压缩通路。
- mHC 图包含 pre 坍缩、Norm 与 Attention/MoE 计算、post 展开、comb 转置混合原多流及 Add。明确 mHC.forward 返回 post/comb/collapsed，分支调用与最终残差合并由 Decoder 执行。
- SWA 不画不存在的压缩器；CSA 保留 Ca/Cb 重叠、独立 Indexer、缓冲/条目/重叠状态及可见性；HCA 与其区分。主 KV、压缩条目与逻辑历史长度分开。新增图不得把 CSA 的 TopK mask 误写为物理裁减 KV。
- MoE 关系层包含路由、命中专家、共享专家和加和；下一层区分 Hash 查表与 TopK 选择、原始 scores 计权、单激活专家和共享专家内部。激活专家 token 数保持符号且不假定每专家收到全部 token。不添加当前源码没有的 latentMoE/Engram。

### 数据流与布局契约

- 箭头表达真实张量依赖，不只表达模块先后。每条数据边保留张量身份和位置相关形状，多消费者状态不能只留下第一条边。辅助参数/控制依赖应注明其身份，不伪造激活张量。
- 主链单向，残差向下游合并，跨调用状态按调用前输入/调用后输出表达。必要同源引用明确标注实际生产位置并可追溯，不能成为省略连接的借口。
- cos/sin 等辅助输入贴近消费点。连线标签与其线段空间关联明确，不出现游离文字、共用线路导致的来源混淆或只有结束箭头的断线。
- 不以省略号、CSS截断、过小字体或删边来换取紧凑。长内容通过换行、合理节点尺寸或明确的层级拆分呈现；完整文字表不是主图截断的替代。
- 画布边界从节点、全部显式路由、箭头、标签、卡片及必要描边/交互效果共同计算，包含负坐标处理；不能只看节点矩形。不得通过无限扩大画布让字体缩小到难读。
- 共享布局修正需检查全部受影响图。正式渲染路径直接支持完整文字与嵌入显示，不能依赖手工改生成后副本来伪装 Archify 原生校验通过。

### 交付与历史保护

- 接入现有 DeepSeek 全变体 Archify 构建与离线入口；精确命令由实现任务按当前接口记录。正式入口默认只呈现 Archify，可保留原旧图文件作为历史，不删除旧候选。
- 新代码、图数据及必要渲染配置进入有效来源身份，生成新候选；不覆盖已验收候选或把旧浏览器记录转用于新 HTML。
- 用户不要求本轮建立跨机器完整复现方案。仍须在现有环境通过文档命令构建交付，并正确记录源码/config/工具/图版本与限制，不把绝对安装路径作为模型结构含义。
- 实施继续委托 dsh；Codex 做规格、复核和协调。此规格发布不代表开始执行、关闭旧票或恢复自动化。其他模型不做功能推广；共享代码有影响时只做必要保护回归。

## Testing Decisions

### 已确认的主验收边界

用户已确认以现有“DeepSeek 构建 → 最终离线 HTML 入口”为主验收边界。一次完整构建产物驱动符号/语义核对、原生图及章节嵌入浏览和历史保护检查，优先复用已有构建接口与公开输出。较低层的语义/图投影/布局测试只补必要故障定位和回归，不替代完整交付验收。

复用现有 DeepSeek 阅读、语义及 Archify 测试先例：四真实层组、部分/逆 RoPE、共享 KV、comb 转置、状态依赖、公开构建输出、来源清单、层级链接与 Excel 一致性。现有旧图快照或旧导航断言若与新规格冲突，按明确行为修改并说明；不得把新增失败一律记作历史失败。

### 可验证验收清单

- [ ] **AC01 构建与来源**：文档给出的正式命令从源码/config 构建新 DeepSeek 候选，缺失/漂移有具名错误；入口、清单与实际图文件一致。模型不实例化、不读取真实权重。
- [ ] **AC02 阶段**：UI恰有Prefill/Decode；逐阶段检查所有可见图、卡片和参数面板，不出现第三类数值场景或示例长度替代符号。
- [ ] **AC03 符号**：从输入到输出逐边核对形状、轴和派生参数；seqlen/kvcachelen含义、窗口上限、压缩条目及输出选取长度正确。对不同合法符号约束不误套特例。
- [ ] **AC04 单套绘图**：整网、Decoder、模块和内部通路中没有旧图与Archify并列的重复展示；原旧文件仍受保护。
- [ ] **AC05 导航**：四层及各分支入口、面包屑/返回、原生图单独打开、源码与参数联查均能离线使用；不出现空白页签、重复ID或失效链接。
- [ ] **AC06 整网**：ForCausalLM到logits主路径完整、Decoder循环与实际层序一致，Embedding/输出端在第一层可查看算子与形状。
- [ ] **AC07 抽象**：逐图检查模块/算子粒度；未展开节点有明确标注及有效后续入口。不得仅靠图标题声称底层全覆盖。
- [ ] **AC08 mHC**：两次分支的collapsed、分支输出、post展开、combᵀ残差混合及Add完整；与当前Decoder源码逐项核对。
- [ ] **AC09 Attention总览**：Q/KV保持关联，每条输入/输出有可识别来源；hidden_states、q_residual、Q、KV、mask/偏置不混用，sinks等参数来源可查。
- [ ] **AC10 Q/KV/O**：具名投影、Norm、布局轴、部分RoPE与逆RoPE及分组输出对应真实实现，未展开内部不能冒充已拆完算子。
- [ ] **AC11 缓存差异**：SWA/CSA/HCA全部有真实入口；调用前/后状态、主KV与压缩KV、缓冲余量、重叠与Indexer差异可核对；所有真实层组有覆盖。
- [ ] **AC12 MoE**：关系层不混入整张专家算子图；Hash/TopK及专家内部可分别进入；选择、计权、共享与激活专家输出加和保持正确。
- [ ] **AC13 就近参数**：每图默认参数只涉及该图，保留完整名称、符号表达式和配置来源；完整权重/源码按需查看，不被删去。
- [ ] **AC14 全图文字**：逐图读取最终SVG/DOM可见文字并与完整节点/标签比较；同时检查运行时CSS截断。主节点、连线、卡片、参数不丢字、不用工具提示补救主图省略。
- [ ] **AC15 全图连线**：公开交付的实际connections/relations与算子输入输出核对；覆盖共享消费者、残差和辅助输入，不只检查内存边列表或字段非空。
- [ ] **AC16 全图几何**：对最终渲染后的节点/标签包围盒、完整路径点和箭头外沿检查画布包容与遮挡；专门复现并阻止mHC等负坐标裁切。
- [ ] **AC17 标签关联与比例**：测量每个标签与所属线段距离、与其他标签/节点重叠及实际投影字号；远离或归属不清项进入人工修复清单。测量记录不能被默认当作视觉合格。
- [ ] **AC18 双入口浏览**：原生图和最终离线章节嵌入页都检查；至少覆盖常用桌面视口1440×900及1920×1080、100%浏览器缩放、页面长图滚动及查看器缩放，逐页签确保内容完整可读。若工具限制环境，记录实际环境和未完成范围。
- [ ] **AC19 实际目检**：为全部最终交付图保留对应截图并逐张查看；至少对整网、Decoder、Attention、mHC、MoE和缓存的嵌入状态另存可追溯截图。每条人工发现的共性问题回查全图库。
- [ ] **AC20 来源绑定**：原生验证、浏览器检查与截图都绑定最终候选和HTML字节；新版重新验证，旧候选81/81或原型静态检查不能沿用为新版通过。
- [ ] **AC21 历史保护**：接手前登记既有候选、Excel与证据清单；验收逐文件/逐字节核对，既有删除保持，不恢复或清理用户改动。必要新增图与旧表行粒度差异明确登记，公式/计费/汇总不变。
- [ ] **AC22 诚实结论**：通过、失败、跳过、环境不可用、人工未目检分别报告。正式浏览门禁未完成时不得靠静态检查或关闭保护的补充运行宣布通过；不得为通过门禁绕过保护。
- [ ] **AC23 整体交付**：提供源码/config范围、正式入口、全图库清单、针对本轮意见的响应、测试与人工证据、已知限制；经Codex复核和用户review后才确认DeepSeek完成。

浏览器检查的具体工具沿既有授权环境执行；不可用时保留未验收状态，不以本规格授权绕过访问限制。SVG边界检测不是浏览器几何/交互/视觉检查。

## Out of Scope

- GLM、Qwen、HiDream等其他模型功能推广，以及本轮之外的新模型/通用任意源码导入。
- 新增性能公式、Excel内部计算改造、Profiler/Nsight/XPU实测、通信/融合/并行估算。
- 新增化简算法、任意符号证明器、ONNX优化或将逻辑图等同后端执行图。
- 模型运行、权重下载/数值分析、训练损失/采样控制等非本轮阅读主路径扩展。
- 独立的大规模架构重构、lint/CI平台建设、跨机环境复制，以及未经另行授权的commit/push。
- 自动验收T14、关闭既有Issues、恢复暂停自动化或自动开始实现。
