## 目标

基于已有工程，展示从整网模块到重复层、单个 Block、内部语义算子的分层结构，避免平铺完整 ONNX 带来的阅读负担。以同源结构数据生成可编辑 Excel，使用用户提供的算子性能公式与 XPU 能力参数进行串行理论性能汇总。

只依据指定版本的模型源码和配置静态分析，不实例化或运行模型，不依赖真实权重数值。结论是理论结构与公式估算，不宣称真实设备实测性能或模型数值等价。

## 分层展示

- 文本模型默认层级：整网模块 → 重复层组 → 单 Block → Attention/FFN 等内部语义算子。HiDream 按其实际网络包含关系组织相应层级，不强套 Decoder 架构。
- 逐级进入并可返回上级；默认只展示当前层级，避免全图无限铺开。
- 默认显示名称、主数据连接、符号 shape；参数、权重明细与源码按需查看。
- 相同结构只展示一份模板，保留真实层归属、顺序和循环次数；有真实结构差异时分别展示。
- 图上保留变量，不因生成性能场景而要求维护另一套结构图。
- 现有详细阅读页、Excel 和 ONNX 资产可作为复用基础；ONNX/onnxsim/Netron 是辅助联查，不作为任意模型自动解析或实际硬件执行的证明。

## 分析参数与算子粒度

- `seqlen`：本次输入的新 token 数。
- `kvcachelen`：调用前已处理的逻辑历史 token 总数；例如历史 4096 token 就填 4096。空缓存 Prefill 取 0。
- 滑动窗口大小、压缩率等来自模型配置，用于推导实际缓存条目与计算维度；物理缓存条目数或占用字节数不能替代逻辑历史长度。
- 缓存推导默认空态起步、连续正常执行，不覆盖任意裁剪、回滚或重置后的自定义缓存快照。
- batch size、计算精度、权重/激活存储位宽、XPU 矩阵/向量能力和带宽等作为性能配置。
- hidden size、头数、层数等默认读取模型配置。用户可自行修改 Excel 做假设计算；工具不新增可编辑架构、结构重建或假设架构校验功能。
- Linear、MatMul 及必要的 reshape、transpose 等按语义操作列出；Norm、Softmax、RoPE、TopK 等保持具名操作，不机械拆成全部微步骤。
- 算子任务不等同于独立设备 kernel；不根据权重数值推断 MoE 实际路由或其他数据相关选择，必要规模应使用显式假设或保持待确定。

## Excel 与理论性能

- 文本模型输出 Prefill、Decode 两个 sheet，消费同一结构的不同参数预设；HiDream 单次网络分析可使用一个 sheet。
- 表内提供参数与算子数据，直接写入用户提供的 Excel 性能公式。修改输入后由 Excel 重算。
- 用户公式是性能分析依据；后续修改沿用该依据，不能擅自用其他估算公式替代。
- 用户于 2026-10-29 确认首版 CUBE/VEC 粗估规则：含矩阵计算的算子按 CUBE，其余按 VEC。CUBE 的 B=1/M=1/K=64/N=64 为 1ms，耗时 `B*M*K*N/4096 ms`；VEC 耗时 `M*N/64 ms`，均按比例、不向64取整。默认吞吐在 Excel 可改；不另加带宽/精度折扣。缺少可确定规模的任务仍标未知，不默认为0。规则已确认不代表性能功能已经实施。
- 逐算子成本 → 模块/循环组小计 → 整网单次调用成本，按串行求和；同构重复使用循环次数汇总，不机械复制全部层和专家。
- 循环中输入规模或条件变化时，按对应实例重新代入；不能将变化的调用成本视为固定值直接乘次数。
- 组小计与内部算子不得重复计入整网总数；公式及参数引用须能追溯。
- 首版不分析任务间并行、算子融合、计算通信重叠或通信耗时，不接入 Profiler/Nsight，不计算完整文本生成或完整采样任务耗时。
