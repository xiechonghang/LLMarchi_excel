## 公式与参数

- 把有效M、分组K、投影N、路由总行数、可见KV长度、压缩条目相关的组合推导与合法性检查提到参数层。基础参数共用，实际有差异的参数分别标清作用域；派生参数必须活公式，不能用构建时数值快照替代输入联动。
- 算子维度格优先是单个绝对参数引用，例如T=$B$3、D=$B$14、M=D行*E行、K=F行、N=$B$25；这些只是引用模式示例，实际地址与真实参数由生成器决定。参数推导复杂时，直接引用对应派生参数格，不能在每个op维度格重复一长串IF/ISNUMBER/内联表达式。
- 耗时格保持可读的行内算术：CUBE约为M*K*N/吞吐，VEC约为n*T*D/吞吐；非法输入守卫可通过参数区的已校验值/简短状态引用表达。上一轮修好的吞吐守卫、未知传播、条件0与固定batch=1必须保留；简化公式不意味着放弃验证。
- 复合矩阵项仍由辅助项SUM/repeat得到工作量，再供主行直接引用。不要为了让M*K*N凑出总量而虚构一个数学上不存在的单矩阵shape。
