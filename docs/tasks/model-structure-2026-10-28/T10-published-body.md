# 10: 按用户公式计算 DeepSeek 算子成本与串行循环小计

## What to build

在用户交付算子 Excel 性能公式后，用户修改 DeepSeek 场景与 XPU 参数即可得到逐算子、模块/循环组及单次网络调用的串行理论成本。

## Acceptance criteria

- [ ] 外部前提：用户提供性能公式、单位及适用算子/精度；未满足时保持 needs-info，不得开始猜测公式。
- [ ] 用户公式直接写入 Excel 并绑定明确参数，后续调整沿用该依据，修改输入后由 Excel 重算。
- [ ] 按算子→模块/循环组→单次调用汇总，不重复计父小计和子项；变化规模按对应实例代入。
- [ ] 不计并行、融合或通信，不等同实测性能；未知路由/规模/公式不能默认为0。
- [ ] 用用户公式的可核对例验证真实公式、单位、引用和总计，交付 Prefill/Decode 性能工作簿。
