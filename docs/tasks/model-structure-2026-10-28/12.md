# T12：Decoder 语义图与可追溯等价化简（DeepSeek 首批）

版本：Decoder 数据流图 vNext（2026-10-30）。无开发前置；用户已授权开启本轮版本，实际开发由 dsh 执行，Codex 验收。

## What to build

在既有静态结构、构建与模型适配上增加可追溯的原始/化简后语义图。先支持 DeepSeek 四种真实层组的 Decoder 计算语义，交付 KV 与完整 Attention 的 Archify 阶段预览，供 T13 接入产品层级浏览。不要只把原图的复合框改名或藏起布局节点。

范围依据：`docs/requirements/decoder_dataflow_refinement_2026_10_30.md`；已认可样式：`.archify/dataflow-deepseek-kv-discussion-20261030-111656/deepseek-kv.html`。保留整网/层组/Block 的同源关系与真实模块/源码身份。

## Acceptance criteria

- [ ] 建立模型无关的语义图/校验/化简接口，DeepSeek 仅声明自身来源与语义。复用现有张量/算子/模块/条件/层组事实，不再建模型解析器或平行构建器。可用独立语义投影保留旧事实接口，避免影响 Excel。
- [ ] DeepSeek 原始语义图能分别辨认 `kv_proj`、RMSNorm、View、Transpose、RoPE，Q 低秩路径、输出投影、压缩/索引/残差/FFN 中的具名计算有来源，Norm/RoPE 等内部微步骤不全部展开。Linear 保留真实实例名；每个新拆分节点映射回原算子与源码。
- [ ] 展示与语义轴映射使用参数全称，区分 `seqlen` 与 `kvcachelen`、逻辑/物理缓存及固定单 KV 头；旧内部别名可保留但不向主图泄露。KV 新投影阶段不错误使用总历史长度。
- [ ] 实施本轮保守白名单：形状表达式化简、恒等变换消除、连续 Transpose 复合/抵消、连续 Reshape/View 合并、可证明的单位轴重排、完整原样 Split/Concat 抵消，以及已明确批准的 Transpose 并入矩阵乘语义。每条有前提/应用或拒绝原因；无法证明则保留。可使用有限、可判定条件，不要求任意符号证明器。
- [ ] 化简保持合法输入域内的值/形状/轴/类型/状态语义，保留共享使用者、广播、分支、原始节点与源码对应；条件依赖场景则显式标注，不能以一个 `seqlen=1` 样例代替通用图。禁止任意计算融合、权重数值折叠、精度变化、跨计算盲合并、删除缓存副作用。
- [ ] `Q @ Kᵀ` 类合并保留轴置换和两算子的来源；不吞掉 batch/head 置换，不宣称已实现设备融合。KV 的 View＋Transpose 在单 KV 头前提成立时可化为一个四维 Reshape，不能抹去三维到四维变化。
- [ ] 从同一语义结果程序生成 DeepSeek KV 与完整 Attention 的可查看 Archify 预览（含原始/化简后的定位或对照、原图/节点对应与参数全称），遵循主链单向、紧凑旁枝、无空分栏。不是手抄讨论稿冒充自动生成。
- [ ] 新语义数据、规则/工具身份、化简审计与预览来源进入本票可复现产物/manifest。以实际源码与文件哈希闭合，不把根 HEAD 当未提交实现的身份，不伪造 Archify 的 repo/commit 证据。
- [ ] 有独立正反例：同形状但不同轴、非逆置换、共享消费者、动态长度、单位轴成立/不成立、Split 分支被消费、缓存/类型边界。仅用生成器自己算 expected 不足以证明正确；用小的确定性张量/索引映射核对无需模型实例或权重。
- [ ] 既有五模型 Excel 字节与 T11 接手工作簿相同；保留原有四组/43层与单层兼容、来源拒绝与旧入口行为。新测试和相关回归通过，历史 ONNX 缺依赖/旧布局失败单列，不掩盖或反复运行昂贵全量。
