# 04: 统一 Excel 导出并提供可填写的分析场景

## What to build

用户在同一套导出能力生成的 Excel 中填写 seqlen、kvcachelen、batch size、精度与存储位宽等配置，查看对应算子、符号/实际规模和真实循环归属。文本模型保留 Prefill/Decode 两页。

## Acceptance criteria

- [ ] 收敛单层/分组工作簿的创建、保存和参数引用，不增加第三套 Excel 导出器。
- [ ] 通用导出支持模型声明的工作表与分组，文本适配生成两页；单页能力可由明确测试输入验证，不宣称 HiDream 已接入。
- [ ] 算子与模块/循环组来自同一结构；参数可追溯，不机械复制全部层或专家。
- [ ] 模型结构默认读取配置；不增加架构编辑器或修改架构后的重建/校验功能。
- [ ] 性能公式尚未提供时明确待提供，不生成猜测耗时，不把缺失成本记为0；给出实际工作簿和引用检查。
