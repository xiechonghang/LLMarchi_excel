# 06: GLM-5.3-Flash 语言主干的分层图与结构工作簿

## What to build

用户能选择 GLM-5.3-Flash，静态阅读其真实语言主干和不同层型，并生成同源工作簿。它是独立适配，不预设与 GLM-5.3 的内部结构相同。

## Acceptance criteria

- [ ] 锁定官方源码和配置身份，不运行模型、不下载权重；缺失源码或不确定维度明确标示。
- [ ] 核对实际不同注意力/状态/FFN 路径及层归属，复用展示与导出接口，不复制整个渲染器。
- [ ] 只覆盖 token 输入至 logits 的语言主干，不展开图像输入路径。
- [ ] 提供可浏览层级图、两页结构工作簿和实际验证证据；没有用户性能公式时保留待提供状态。

## 执行与阶段结果

实际产品开发由 dsh 执行，Codex 负责派单和复核。优先复用并原位重构既有工程，保护接手前未提交改动，不自动提交或推送。每票提供可打开或可验证的产物、实际测试结果、复用/重构/删除/新增清单及未验证范围；静态工程通过不代签用户阅读验收。
