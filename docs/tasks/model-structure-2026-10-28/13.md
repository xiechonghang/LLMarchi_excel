## What to build

复用 T12 的同源语义图与安全化简，将 Archify 底层图接到现有 DeepSeek 整网 → 层组 → Block/模块 → 内部计算的产品阅读路径。以完整 Decoder 的 Attention、FFN/MoE、mHC/Norm/残差为重点，不停留于一张孤立 KV 演示。

## Acceptance criteria

- [ ] 四种真实层组/43层归属保持，当前层级按需进入与返回，不无限铺开全网。用户能从产品入口直接找到 Decoder/Attention/FFN 的新图。
- [ ] 底层 Archify 图由 T12 语义结果程序生成，原始/化简结构和详情对应一致；实例名、参数全称、形状、来源、未知/条件均能追溯。
- [ ] 主链单向拓扑排布、分支向下游汇合，缓存表达前态输入/后态输出；cos/sin 等只占局部旁枝，无空的 01/02 分区或蛇形回流。主图不因过宽、微小字体或堆砌信息而失去可读性。
- [ ] 参数/权重/源码详情按需展开，保留导航与返回上下文；离线可打开，不能依赖一次性本机 HTTP 服务。可用关联子页，不得只给无入口的孤立演示。
- [ ] 真实浏览器完成一条 整网→层组→Block→Attention/KV→FFN→返回 路径；覆盖各结构变体、关键分支/残差、全称标签与实际路线，无向上回指/遮挡/断链。Archify 按技能完成真实 finalize/browser 检查并看渲染图，不伪造通过。
- [ ] 页面与新增语义/Archify工具版本/规则进入新候选身份；同输入重建可复现或具名披露不可复现环节，不能将随机构建参数误作模型变化。历史候选不覆盖。
- [ ] 复用已有构建/路由/来源联查，删除被本票明确替代的重复逻辑前先验证调用引用，不另造第二套产品。其余四模型旧图保持可用，五模型 Excel 仍逐字节不变。
