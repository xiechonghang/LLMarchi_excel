# 05: GLM-5.3 语言主干的分层图与结构工作簿

## What to build

用户能选择 GLM-5.3，静态阅读 token 输入到 logits 的语言主干，并生成同源结构工作簿。沿用已完成的层级浏览和导出能力，仅新增该模型必要的源码解释与规则。

## Acceptance criteria

- [ ] 锁定官方源码及配置版本，不实例化或运行模型，不下载权重；来源不足时明确限制，不冒充通用支持。
- [ ] 实际 Attention/FFN、归一化、残差、缓存、层型差异按该实现表达，不复制 DeepSeek 模型事实。
- [ ] 语言主干可逐级进入和返回；视觉及图像输入路径不在本票范围。
- [ ] 输出包含 Prefill/Decode 场景与符号 shape 的 HTML/Excel；提供实际产物、来源和有意义的语义验证。
