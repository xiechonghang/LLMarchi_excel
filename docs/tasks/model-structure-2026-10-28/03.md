## Acceptance criteria

- [x] 复用现有图连接、源码快照、算子卡和 ONNX 联查；参数/权重/源码按需查看，层级进入和返回实际可用。
- [x] seqlen 表示本次新 token 数；kvcachelen 表示逻辑历史 token 数，空缓存 Prefill 为0；窗口和压缩缓存规模从配置与连续执行前提推导。
- [x] 缓存、分支、残差和共享关系不会因折叠丢失；已知条件与未知条件诚实标示。
- [x] 用少量有区别的 Prefill、非零历史 Decode、窗口闭合场景核对语义；替换旧默认长页装配并清理已迁移重复实现。
- [x] 提供可打开 HTML 与实际导航检查；静态测试不代签用户阅读认可。
