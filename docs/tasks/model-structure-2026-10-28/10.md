# 10: 按用户公式计算 DeepSeek 算子成本与串行循环小计

## What to build

在用户交付算子 Excel 性能公式后，用户修改 DeepSeek 场景与 XPU 参数即可得到逐算子、模块/循环组及单次网络调用的串行理论成本。

## Acceptance criteria

- [x] 外部前提：用户已确认 CUBE/VEC 首版粗估公式与 ms 单位（2026-10-29）；未声明精度折扣，先按相同用户基准计算，不伪造实测。
- [x] 用户公式直接写入 Excel 并绑定明确参数，后续调整沿用该依据，修改输入后由 Excel 重算。
- [x] 按算子→模块/循环组→单次调用汇总，不重复计父小计和子项；变化规模按对应实例代入。
- [x] 不计并行、融合或通信，不等同实测性能；未知路由/规模/公式不能默认为0。
- [x] 用用户公式的可核对例验证真实公式、单位、引用和总计，交付 Prefill/Decode 性能工作簿。
