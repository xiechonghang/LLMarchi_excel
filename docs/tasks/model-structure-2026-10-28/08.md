# 08: HiDream-O1-Image 单次生成网络的分层图与单页工作簿

## What to build

用户能阅读 HiDream-O1-Image 单次神经网络 forward，从必要的输入嵌入到主干及输出投影，生成一页结构工作簿，不把外部采样与调度流程混进网络分析。

## Acceptance criteria

- [ ] 锁定官方 HiDream-O1-Image 源码与配置身份，不下载权重、不实例化或运行网络。
- [ ] 保留实际存在的像素/patch 输入、时间步嵌入、神经网络主干与输出投影，不套用模型没有的 CNN/VAE/独立文本编码器。
- [ ] 不分析 scheduler/solver、外部采样迭代、外围控制或完整出图耗时。
- [ ] 沿实际网络包含关系逐级阅读，不强套 Decoder/Prefill/Decode；同一导出核心生成单 sheet。
- [ ] 交付真实 HTML/Excel 和来源/连接/维度核对证据；未知内容明确标注。
