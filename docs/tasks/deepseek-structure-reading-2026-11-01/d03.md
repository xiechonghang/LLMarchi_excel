# [D03] Attention总览、Q/KV/O与三类缓存

## Parent

[正式规格 #16](https://github.com/xiechonghang/LLMarchi_excel/issues/16)。仅DeepSeek，不推广其他模型。

## What to build

在正式四层阅读中保持Q/KV关联的Attention总览，向下进入Q、KV、O、SWA/CSA/HCA缓存、压缩器及Lightning Indexer，按真实层型表达差异。不为补标注而把总览拆散。

## Acceptance criteria

- [ ] 总览连接hidden_states、Q、q_residual、当前/可读KV与mask；sinks/scaling来源可查，没有无来源引用或只有结束箭头的断线。
- [ ] Q/KV/O保留具名Linear、Norm、布局轴、部分/逆RoPE、分组输出与实际符号维度。
- [ ] 真实层组均能进入对应SWA/CSA/HCA；逻辑历史、主KV、压缩条目、缓冲余量和调用前/后状态分开。
- [ ] SWA无压缩器；CSA保留Ca/Cb重叠、独立小压缩器/Indexer及mask选择；HCA保持自身压缩与可见性，不能套用CSA。
- [ ] Indexer接收正确q_residual/hidden_states及自身压缩状态；不把外层CSA压缩KV误当其唯一输入，不把TopK mask画成物理缩减KV。
- [ ] 所有真实消费者和条件分支与源码核对；辅助cos/sin局部接入，复合模块未展开时有有效后续入口。
- [ ] 回归Q→Attention游离标签及缓存/Indexer负坐标裁切；所有受影响图统一检查完整文字、标签归属、遮挡、边界和投影比例，不用大留白或小字掩盖。
- [ ] 正式构建到原生/嵌入页面均检查并保留最终候选证据；Excel/旧候选不变，未完成门禁如实声明。

覆盖AC03、AC05、AC07、AC09—AC11、AC13—AC17；全局AC01—AC04、AC18—AC22适用。实施由dsh完成并停待Codex复核。
