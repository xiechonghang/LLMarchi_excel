## Acceptance criteria

- [ ] 第三层只展示模块关系，专家内部在第四层；导航/返回/来源与就近参数完整。
- [ ] Hash以tid2eid[input_ids]查表选择；TopK以纠偏后分数选择；两者使用原始scores gather计权、归一化并缩放。
- [ ] 路由indices/weights、激活token、专家输入及回填依赖完整，形状和来源清晰。
- [ ] 单专家展示实际gate_up_proj、拆分、Clamp/激活、乘法、down_proj；共享专家保留独立投影和全token输入。
- [ ] expert_token_count保持符号，不假设所有专家或全部token参与每个激活专家；不虚构Engram/latentMoE。
- [ ] 专家输出加权、IndexAdd/View及共享输出加和顺序正确；新增图与旧表粒度差异登记，Excel不改。
- [ ] 回归Hash/TopK游离标签和MoE裁切；所有关系/专家图统一检查完整文字、线条与标签、画布边界和原生/嵌入显示。
- [ ] 交付可构建的新候选、测试与来源/显示证据；保护历史文件，失败/跳过/未目检如实分列。
