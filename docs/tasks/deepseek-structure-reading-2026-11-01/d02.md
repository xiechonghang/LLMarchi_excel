# [D02] Decoder与mHC完整分支数据流

GitHub: [18](https://github.com/xiechonghang/LLMarchi_excel/issues/18)

## Parent

[正式规格 #16](https://github.com/xiechonghang/LLMarchi_excel/issues/16)。仅DeepSeek，沿已认可第八版方向。

## What to build

从正式入口进入单个Decoder，读清两段mHC、Norm、Attention、MoE与残差，并进入mHC权重细图。Attention/MoE内部可先连接既有实现，其专门阅读改进由其他切片完成。

## Acceptance criteria

- [ ] 从真实结构事实生成Decoder，不把所有层型当成同一模块组合。
- [ ] attn_hc与ffn_hc都表达collapsed→Norm→分支计算→branch_output→post展开，以及combᵀ混合原多流后Add。
- [ ] 明确mHC.forward返回post/comb/collapsed；分支调用和合并发生于Decoder，不虚构mHC回调，不画向上回流。
- [ ] 权重细图包含实际具名投影、拆分、门控及Sinkhorn循环；未展开复合模块有说明和有效入口。
- [ ] 每个残差、门控与状态消费者依赖保留，逐边有身份、形状、来源，全称参数就近提供。
- [ ] 回归mHC左侧裁切，检查节点、显式路线、标签与箭头外沿，不只比较节点矩形。
- [ ] 公开两阶段、层间/图间导航与返回可用；全部受影响图做原生及嵌入检查，保留最终来源和显示证据。
- [ ] 新候选不覆盖旧产物，Excel与历史证据逐字节保持，失败/跳过/未目检分列。

覆盖AC05、AC07、AC08、AC13—AC17；全局AC01—AC04、AC18—AC22适用。实施由dsh完成并停待Codex复核。
