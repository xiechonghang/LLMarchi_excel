# [D01] 正式阅读入口与整网简单端点

GitHub: [17](https://github.com/xiechonghang/LLMarchi_excel/issues/17)

## Parent

[正式规格 #16](https://github.com/xiechonghang/LLMarchi_excel/issues/16)。仅DeepSeek；原T14不因此验收。

## What to build

从现有DeepSeek正式构建到可打开的离线HTML，只用Archify、只选择Prefill/Decode；整网显示真实Decoder层序/循环，并在第一层展开Embedding及HyperHead→Norm→lm_head。接入四层导航契约和可复用的现有子图，后续切片在此入口更新内容。不交空白占位、假链接或仅内部API。

## Acceptance criteria

- [ ] 正式构建生成新候选及来源记录，不实例化模型或读取真实权重。
- [ ] 可见阶段恰为Prefill/Decode，图和参数保留seqlen/kvcachelen等符号；不强制Decode长度为1，不改Excel场景。
- [ ] 正式入口不重复呈现旧SVG与Archify；旧文件/候选保留。
- [ ] 整网对应ForCausalLM；循环次数、层序来自config，模板不表示共享权重。
- [ ] Embedding与输出端有具名算子、形状及就近参数；HyperHead不冒充单算子，输出位置由logits_to_keep约束。
- [ ] 四层导航接入真实可访问内容；返回、单开、源码和参数联查均离线可用。阶段性未交付范围如实声明。
- [ ] 对本票新增及共享页面改动影响的全部图做完整文字、来源/形状、路径边界、标签关联及原生/嵌入检查。
- [ ] Excel和历史产物逐字节保护，证据绑定本票最终候选；失败、跳过、未目检分别列出。

覆盖父规格AC01—AC07、AC13；AC14—AC22适用于本票全部公开范围。每票均需遵守父规格的全票共同约束，显示验收不能推迟到D05。实施由dsh完成并停待Codex复核。
