# [D05] DeepSeek全图库验收与正式交付

GitHub: [21](https://github.com/xiechonghang/LLMarchi_excel/issues/21)

## Parent

[正式规格 #16](https://github.com/xiechonghang/LLMarchi_excel/issues/16)。父规格AC01—AC23全部收口。

## What to build

冻结前述切片最终实现，重建一套完整DeepSeek正式候选，对全部图做来源/语义、显示与原生/嵌入浏览复核，交用户整体review。不是将前序票的可读性检查拖到最后，而是验证同一最终候选的完整一致证据。

## Acceptance criteria

- [ ] 最终源码冻结后按文档命令重建；所有入口、阶段、图/参数/源码符合AC01—AC23并逐项提供证据。
- [ ] 从最终实际产物枚举全图清单，含层型、路由、形态与入口；不把草稿21图当作覆盖上限。
- [ ] 全图语义逐边核对；逐图检查可见全文、标签归属/距离、节点/路径/标签/箭头边界、遮挡和实际投影字号。
- [ ] 全部最终图有截图并逐张查看；整网、Decoder、Attention、mHC、MoE、缓存另有嵌入状态截图。
- [ ] 覆盖1440×900和1920×1080桌面视口、100%浏览器缩放、各页签/返回、长图滚动及查看器缩放；工具限制明确列出。
- [ ] 原生门禁、浏览器检查与人工目检绑定最终HTML；不沿用旧候选81/81，不以关闭保护的补充运行代替正式门禁。
- [ ] 失败/跳过/环境不可用均单列，门禁或实际目检未完成则保留待验收，不虚构完成。
- [ ] Excel、历史候选与证据逐字节保持；提供图↔旧表粒度对应、本轮意见响应、来源版本与已知限制。
- [ ] 提供可直接打开的正式入口，停待Codex复核与用户review；未确认前不推广其他模型，不自动关闭父规格/T14或恢复自动化。
